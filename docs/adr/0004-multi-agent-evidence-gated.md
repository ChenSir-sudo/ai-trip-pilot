# 多 Agent 的保留是有条件的：消融通不过就降级为单 Agent

多 Agent 是本项目的学习目标之一，因此天然存在「为了用而用」的诱惑。但组合决策已交给求解器，若再设交通 / 住宿 / 活动三个独立角色，它们会各自给出局部最优并相互冲突，而收益无法被证明——「角色名称本身不构成架构价值」。

我们决定：只保留三个职责明确的角色（候选筛选、解说、影响面分析），并且**它们的存废由消融实验裁决**。回归集上跑「单 Agent + 求解器」与「双 Agent + 求解器」两组，观测软偏好满足度、成本与 P95 延迟。若无可观收益，代码与文档一并降级为单 Agent，并把该结论写入 README 与设计文档。

## 影响

- 这是对本项目自身卖点的**主动证伪条款**。它让「用了多 Agent」与「证明了多 Agent 有用」成为两件必须分开回答的事。
- 实验成本很低（同一评测集换一个编排形态），但收益很高：无论结论是哪一边，都得到一个可讲述的真实判断，而不是一个无法辩护的技术选择。
- 若结论是降级，此前关于「多 Agent 编排」的学习目标由影响面分析与候选筛选中保留的并行扇出来满足，学习目标不落空。
